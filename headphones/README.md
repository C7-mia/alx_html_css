# Headphones Landing Page

This project is a pixel-perfect HTML/CSS implementation of a Headphones landing page, designed by Nicolas Philippot. It is part of the ALX Front-End curriculum.

## 📐 Design

The original design was provided in [Figma](https://www.figma.com/file/7G6vL5zKpQG4nK7jvKeuTS/Headphones?type=design&node-id=0-1), which was duplicated to my drafts to access all dimensions, colors, and typography.

## 🚫 Restrictions

- No JavaScript
- No CSS frameworks like Bootstrap or Tailwind
- No external libraries

## ✅ Features

- Responsive design (mobile-friendly at screen width ≤ 480px)
- Max width of 1000px, centered layout
- Custom font usage (Source Sans Pro & Spin-Cycle-OT)
- Hover effects on links and buttons
  - Links: `#FF6565`
  - Buttons: `opacity: 0.9`
